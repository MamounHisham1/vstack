Install vstack

One plugin for everything, one command per skill, or slash commands in OpenCode.

Plugin install (all skills, Claude Code v2.1.275+)

Installs the vstack plugin with every v- skill. Skills run namespaced, e.g. /vstack:v-build.

claude plugin marketplace add MamounHisham1/vstack
claude plugin install vstack@vstack

Or inside a Claude Code session:

/plugin install vstack --marketplace MamounHisham1/vstack

Per-skill install (skills CLI)

Install a specific skill:

npx skills add MamounHisham1/vstack --skill <skill-id> -y

Install everything:

npx skills add MamounHisham1/vstack --skill '*' -y

OpenCode slash commands

This repo ships slash commands in .opencode/commands/, so each skill works as /<skill-id>:

/v-build
/v-copy-me
/v-fill-me
/v-humanize
/v-skill-creator

No install step needed inside this repo — just type the slash command.

Plugin install

Installs the vstack plugin with every v- skill. Skills run namespaced, for example /vstack:v-build.

  1. Add the marketplace and install the plugin.
    claude plugin marketplace add MamounHisham1/vstack claude plugin install vstack@vstack
  2. Or run it inside a Claude Code session.
    /plugin install vstack --marketplace MamounHisham1/vstack
Requires Claude Code v2.1.275+. After install, the skills are available as /vstack:v-build, /vstack:v-fill-me, and so on.

Install one skill

The skills CLI installs a single card into the agent you choose. Replace the skill ID with any card from the catalog.

01 v-build

Build features

Build features end-to-end with parallel subagents — decompose big features into subagent-sized slices or fan out batches of small ones, then split into PRs, severity-gated review, sequential merge + local sync.

npx skills add MamounHisham1/vstack --skill v-build -y
02 v-copy-me

Capture a workflow

Extract workflow patterns from the current session and create or update v- skills in the vstack repo. Use when asked to copy, learn, or save how work gets done into skills.

npx skills add MamounHisham1/vstack --skill v-copy-me -y
03 v-fill-me

Catch up

Catch up on uncommitted, untracked, unpushed, and recently pushed work across the repo and worktrees. Use when the user asks to fill me in or what happened while away.

npx skills add MamounHisham1/vstack --skill v-fill-me -y
04 v-humanize

Rewrite plainly

Rewrite long or technical AI output into plain human-readable language. Use when the user asks to humanize, simplify, or re-explain the last output.

npx skills add MamounHisham1/vstack --skill v-humanize -y
05 v-skill-creator

Create a skill

Create a new v- prefixed skill in the vstack repo. Clarify requirements first, scaffold SKILL.md plus slash command, strip personal data, push to GitHub, and install via skills.sh.

npx skills add MamounHisham1/vstack --skill v-skill-creator -y
The CLI remembers your last selection. It reuses the agents you picked the next time you install, so you do not have to answer the same prompt again.

OpenCode

The repo ships slash commands in .opencode/commands/, so each skill works as /<skill-id> inside this repo. No install step is needed there.

/v-build /v-copy-me /v-fill-me /v-humanize /v-skill-creator

To use a skill in another project, install it through the skills CLI command above.

Verify

List what is installed for your agents:

npx skills list
Command missing? Check that you installed for the agent you are actually using. The plugin path is Claude Code-specific; the CLI path follows the agents you selected.

Questions

Do I need both the plugin and the skills CLI?
No. Use one path. The plugin is the fastest way to get all five skills into Claude Code. The CLI is for one card, a different agent, or a project-local install.
Where do the skills live?
Each skill is one readable file at skills/<skill-id>/SKILL.md. Open the source before you run it.
Does this work without Claude Code?
The skills are plain files. The plugin path is Claude Code-specific; the CLI path installs into the agents the skills CLI supports. This repo also ships OpenCode slash commands.
Is it free?
Yes. vstack is MIT licensed. There is no account, no hosted service, and no usage limit on the skills themselves.

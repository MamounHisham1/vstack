Plugin install

Claude Code only. Installs all five skills as a plugin, namespaced under /vstack.

  1. Add the marketplace and install the plugin.
    claude plugin marketplace add MamounHisham1/vstack claude plugin install vstack@vstack
  2. Or run it inside a Claude Code session.
    /plugin install vstack --marketplace MamounHisham1/vstack
Claude Code v2.1.275+. After install the skills are available as /vstack:v-build, /vstack:v-fill-me, and the rest.

One skill

Use the skills CLI to install a single card. It works with the agents the CLI supports.

npx skills add MamounHisham1/vstack --skill v-build -y

Use --global to make the skill available in every project.

Verify

List what is installed. Global installs use --global; project installs use the default scope.

npx skills ls -g npx skills ls -g -a <agent-id>
Claude Code plugin: confirm the installer reported success, or open /plugin in Claude Code and check that vstack is installed.

Questions

What does install.md do?
It is a prompt for your AI agent. It detects the agents on your machine, asks which ones should get the skills, installs all five, and reports what changed.
Which agents can it install into?
The skills CLI supports Claude Code, OpenCode, Codex, Cursor, Gemini CLI, Windsurf, Cline, Roo Code, Amp, Aider, Goose, Crush, Kilo, Qwen, and more. The agent shows you what it detects before it installs.
Do I need to run anything myself?
No. Give the link to your agent and answer its question. The manual commands on this page are a fallback for when you want to run the install yourself.
Where do the skills live?
Each skill is one readable file at skills/<skill-id>/SKILL.md. Open the source before you run it.
Is it free?
Yes. vstack is MIT licensed. There is no account, no hosted service, and no usage limit on the skills themselves.

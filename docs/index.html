Install

One plugin installs all five skills. Data loads from ./data/skills.json.

Claude Code plugin (recommended)

claude plugin marketplace add MamounHisham1/vstack
claude plugin install vstack@vstack

Per-agent installs

  • Claude Code shell: npx skills add MamounHisham1/vstack --skill '*' -y
  • OpenCode: slash commands ship in-repo; browse skills.sh for one-click add
  • Single skill: npx skills add MamounHisham1/vstack --skill v-build -y

Why vstack

Small conventions that keep agent workflows safe and shippable.

  • v- prefix namespacing

    Every skill ID starts with v- and ships with a matching slash command, so plugin and CLI installs never collide.

  • Single-file skills

    Each skill is one reviewable file. No build step, no hidden dependencies — open it, read it, trust it.

  • Sanitized by default

    Workflows strip personal data and secrets before anything leaves the repo. Share commands, not credentials.

  • PR-based shipping

    v-build fans out parallel slices, gates on review severity, then merges and syncs. v-fill-me catches you up after.

Reference notes

What keeps the collection honest.

Small conventions keep the workflow safe. There is no hidden runtime, and every rule is written to survive a real task.

Namespaced by default

Every skill starts with v- and ships with a matching slash command, so plugin and CLI installs never collide.

One file, no runtime

Read the entire skill before you trust it. No hidden dependencies, no build step, no service to sign up for.

Sanitized by default

Workflows strip personal data and secrets before anything leaves the repo. Share commands, not credentials.

PR-based shipping

v-build fans out parallel slices, gates on review severity, then merges and syncs. v-fill-me catches you up after.

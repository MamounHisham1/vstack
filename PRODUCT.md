# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Static HTML, CSS, and vanilla JavaScript deployed to GitHub Pages. No frontend build step; `scripts/build-skills-json.mjs` regenerates the catalog data.

## Users

Developers who work with coding agents, primarily Claude Code and OpenCode users arriving from GitHub, skills.sh, or shared links. Secondary audiences: the author, using the site as a living reference, and people evaluating the author's craft. Visitors are usually in a terminal-adjacent context, deciding whether a skill is worth installing.

## Product Purpose

vstack is a personal collection of agent skills distributed as one Claude Code plugin or installed individually through the `skills` CLI. The site exists to make the collection legible and to get a visitor to install the plugin or a single skill. Success is a completed install command, not time on page.

## Positioning

Every skill starts with `v-`, ships as one readable `SKILL.md`, and has a matching slash command. They are built for shipping real work: `v-build` decomposes features across parallel subagents and lands reviewed PRs; `v-fill-me` reconstructs what happened across branches and worktrees; `v-humanize`, `v-copy-me`, and `v-skill-creator` close the loop from output to workflow to new skill. No hidden runtime, no proprietary service, MIT licensed.

## Operating Context

Visitors read the site beside a terminal, often after seeing a repo or a skills.sh listing. They copy a command, paste it into a shell or a Claude Code session, and verify with `npx skills list`. Commands must be exact, copyable, and visible without hunting. The five skills and their descriptions are real product facts and must stay accurate.

## Capabilities and Constraints

- Five skills: `v-build`, `v-copy-me`, `v-fill-me`, `v-humanize`, `v-skill-creator`.
- One Claude Code plugin (`vstack`) installs all five; per-skill installs go through `npx skills add MamounHisham1/vstack --skill <id> -y`.
- OpenCode slash commands ship in `.opencode/commands/` as `/<skill-id>`.
- Static site only. Must work on GitHub Pages, without a server, and remain usable without JavaScript for core content.
- The catalog reads `docs/data/skills.json`; generated by `scripts/build-skills-json.mjs`.
- MIT licensed.

## Brand Commitments

The name is `vstack`. The existing tagline "skills that ship" is a confirmed voice anchor. Tone is direct, technical, and understated; no hype, no invented proof. The `v-` prefix is part of the identity.

## Evidence on Hand

Real skill descriptions in `docs/data/skills.json` and `skills/*/SKILL.md`; real install commands in `README.md` and `.claude-plugin/`; real repository at github.com/MamounHisham1/vstack. There are no testimonials, customer logos, usage metrics, or benchmarks. Do not fabricate any.

## Product Principles

1. Show the command, not a claim about the command.
2. The smallest useful surface: five skills, one plugin, no filler.
3. Every skill is readable source; trust comes from inspection.
4. Ship through real workflow: parallel slices, reviewed PRs, merged results.
5. Understate. Let the work carry the pitch.

## Accessibility & Inclusion

Core content must remain readable without JavaScript. Keyboard access, visible focus, reduced-motion support, and WCAG AA contrast are required.
